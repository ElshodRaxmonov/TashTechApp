# TashTech Student Assistant App

A student-focused Android app designed to bring essential TashTech university tools into one place.

![TashTech Banner](app/banner.svg)

### Features
- **Schedule** — access your timetable and manage personal events.
- **QR Attendance** — quickly open the attendance scanner.
- **SIS & LMS** — access university platforms.
- **Tech News** — explore technology news.
- **Reminders & Notes** — keep daily tasks organized.
- **TashBox** — take a quick break with a logic mini-game.
- **Home-screen Widgets** — access key features directly from your launcher.

### Tech Stack
Kotlin · Jetpack Compose · Android

### Status
Developed as an independent student project for the TashTech community.
